# MasterLedger

端末内に帳簿を保存する個人向け複式簿記PWA。現在の保守版は **v2.7.8** です。

[更新履歴](CHANGELOG.md)

## 更新とデータ

- 既存の `ml_v02_accounts` / `ml_v02_entries` とIndexedDB `MasterLedgerPrivate` を引き継ぎます。
- 起動だけで既存のlocalStorageを書き換えません。IndexedDBに初回更新前の退避 `before-v2.7.8` を作成します。
- 更新後はオンラインで一度開き、開いているMasterLedgerをすべて閉じて開き直し、「MasterLedgerについて」でバージョンを確認してください。
- サイトデータの削除は帳簿も削除します。定期的にExcel形式の外部バックアップを保存してください。
- CSVの数式注入対策により、数式と誤認される文字列には先頭のアポストロフィが付きます。

## セキュリティ

取り込み文字列はHTMLとして実行せず表示します。新規仕訳は実在する日付と正の安全な整数金額を検証し、取り込みは10MB・20,000件までに制限します。不正な行のある取り込みは全件中止します。ライブラリは `vendor/` に同梱し、外部CDNから実行コードを取得しません。

CSPで外部送信、外部スクリプト、プラグイン等を制限します。既存の画面操作との互換性のためインラインスクリプトは許可しています。CSPだけでXSSを防ぐ設計ではなく、表示時のエスケープが主な対策です。

アプリ独自の暗号化・認証はありません。端末ロック、ブラウザ拡張、同一オリジン上の他のアプリ、配信元アカウントの管理もデータ保護に影響します。

## 開発時の検証

Node.js 20以上で `npm ci`、`npm test` を実行します。テストはjsdomによるDOM操作、実際のExcel読込・出力、fake-indexeddbによる保存・復元、Service Workerイベントの検証です。iPhone Safariの実機・PDF描画・ブラウザによるCSP適用は別途確認が必要です。
